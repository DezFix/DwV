# DwV 0.2.0

## Что нового

- Торренты: перед стартом окно со списком файлов. Папки выбираются целиком, есть «Выбрать все / Ничего» и размер выбранного.
- В деталях торрента — список файлов с процентом загрузки каждого.
- Главный список стал таблицей: липкая шапка, сортировка по клику, колонки «размер», «статус», «прогресс», «скорость», «осталось», «добавлено».
- Вторая строка у файла: сайт-источник и тип.
- «Продолжить», «Пауза» и «Удалить» в списке работают с выделенными загрузками, чекбокс в шапке выделяет всё.

## Исправлено

- Однофайловые торренты сохраняются по правильному пути и открываются из истории.
- «Продолжить» для торрента, которого нет после перезапуска, больше не врёт, что загрузка идёт.
- После завершения торрента история указывает на настоящий файл, а не на папку с его именем.

## Файлы

- `DwV_0.2.0_x64-setup.exe` — установщик.
- `DwV-0.2.0-portable.exe` — портативная версия.
- `DwV_0.2.0_x64_en-US.msi` — MSI.
- `dwv-firefox-1.2.6.xpi` — подписанное расширение для Firefox/LibreWolf.
