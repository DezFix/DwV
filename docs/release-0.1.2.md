# DwV 0.1.2

Исправление загрузок с файлообменников и защита от дубликатов. Менеджер загрузок для Windows: файлы, видео и торренты в одном приложении.

## Скачать

- `DwV-0.1.2-setup.exe` — установщик (рекомендуется).
- `DwV-0.1.2-portable.exe` — портативная версия.
- `DwV-0.1.2-x64.msi` — MSI.
- `dwv-firefox-1.2.2.xpi` — расширение для Firefox/LibreWolf.

Запустите DwV один раз, чтобы зарегистрировался `dwv://`. Инструкция по расширению: `extension/INSTALL.md`.

## Что исправлено

- Файлообменники: расширение передаёт cookies, Referer, User-Agent и final_url; приложение использует их в запросе. Вместо 4 КБ HTML-заглушки скачивается настоящий файл.
- HTML-заглушка больше не сохраняется как битый архив: загрузка завершается понятной ошибкой.
- Автозапуск из расширения больше не добавляет ссылку дважды.
- Защита от дубликатов: ручное добавление спрашивает «скачать с новым именем» или «не скачивать». Загрузки из расширения автоматически получают имя `файл (1).расширение` и не перезаписывают существующие.
- Торренты с существующим именем не запускаются; yt-dlp не перезаписывает готовые видео.
- Квадратная плитка типа файла (MP4, ZIP, PDF) работает как чекбокс массового выделения.
- Иконки DwV в приложении и расширении; расширение 1.2.2.

## Проверено

- Авторизованный файл: сервер без cookies отдаёт HTML, с cookies — 2 МБ. Приложение скачало 2 МБ.
- HTML-заглушка: строка ошибки, файл не создан.
- Дубликат: диалог с `sample.zip` / `sample (1).zip`; переименование и отмена.
- Дубликат из расширения: автоматическое имя `sample (2).zip`.
- Тесты расширения, cargo и npm.

## Ограничения

- Незавершённые торренты и видео не возобновляются после перезапуска приложения.
- DHT и max peers применяются к новой торрент-сессии; лимиты скорости работают сразу.
- XPI не подписан. Для постоянной установки в Firefox Release нужна подпись AMO; используйте LibreWolf/Developer/ESR или временную установку.
- Если файлообменник требует POST или капчу, одной передачи cookies может быть недостаточно; приложение покажет ошибку.
