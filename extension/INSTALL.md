# Установка расширения DwV

Расширение проверено в LibreWolf. Также работает в Firefox 115+ и Chrome 116+
(в Chrome — через «Загрузить распакованное»).

Файл сборки: `extension/dist/dwv-1.2.10.xpi`.

## Перед установкой

1. Запустите DwV хотя бы один раз — приложение регистрирует протокол `dwv://`.
2. Проверьте, что приложение запускается и открывается окно.

Если протокол не зарегистрирован (например, используется portable `dwv.exe`),
выполните в PowerShell, заменив путь на свой:

```powershell
reg add "HKCU\Software\Classes\dwv" /ve /d "URL:dwv Protocol" /f
reg add "HKCU\Software\Classes\dwv" /v "URL Protocol" /d "" /f
reg add "HKCU\Software\Classes\dwv\shell\open\command" /ve /d "\"C:\Path\To\dwv.exe\" \"%1\"" /f
```

Либо просто запускайте DwV вручную перед скачиванием: расширение работает и
без автоматического запуска, но тогда кнопка «Открыть DwV» не сможет поднять
приложение, если оно закрыто.

## Вариант A. Временная установка (LibreWolf и Firefox)

Подходит для проверки. Расширение исчезает после закрытия браузера.

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Load Temporary Add-on…** (Загрузить временное дополнение).
3. Выберите `extension/dist/dwv-1.2.10.xpi` или `extension/firefox/manifest.json`.
4. Если браузер спросит доступ к сайтам, разрешите его.

После перезапуска браузера повторите шаги 1–3.

## Вариант B. Постоянная установка без подписи (LibreWolf)

Обычный Firefox из релизного канала требует подписанные дополнения и не даст
отключить проверку. Используйте LibreWolf или Firefox Developer Edition / ESR
с отключённой проверкой подписей. Временная установка из варианта A работает
везде.

1. Откройте `about:config`.
2. Примите предупреждение и создайте параметр
   `xpinstall.signatures.required` типа Boolean со значением `false`.
   Если параметр уже есть, переключите его в `false`.
3. Откройте `about:addons`, нажмите шестерёнку и выберите
   **Install Add-on From File…** (Установить дополнение из файла).
4. Укажите `extension/dist/dwv-1.2.10.xpi` и подтвердите установку.

## Проверка

1. Нажмите значок DwV на панели браузера.
2. В шапке должен быть зелёный индикатор и надпись «DwV запущен».
3. Кнопка «Открыть DwV» запускает приложение, если оно закрыто, и показывает
   результат под кнопкой.
4. Включите «Плагин включён», «Перехватывать файлы» и «Перехватывать видео».
5. Откройте страницу с видео: список появится в разделе «Видео на странице».

## Если что-то не работает

- «DwV не запущен» — запустите приложение вручную или проверьте протокол
  `dwv://` командами выше.
- Кнопка «Скачать» пишет «Не удалось» — приложение не ответило за 20 секунд.
  Запустите DwV и повторите.
- Видео не появилось в списке — обновите список кнопкой «Обновить». Потоковые
  плееры иногда отдают видео только после начала воспроизведения.
- Расширение установлено, но ничего не перехватывает — проверьте, что
  «Плагин включён» и нужный переключатель захвата включены.
