# DwV 0.3.0 (черновик, не выпущено)

## Новое

- Видео можно ставить на паузу и продолжать. DwV останавливает yt-dlp, а при продолжении тот докачивает с того же места.
- После перезапуска всё, что качалось, продолжается само: файлы с места остановки, торренты с проверкой уже скачанного, видео с места остановки.
- Загрузки из истории (приостановленные, с ошибкой, отменённые) можно продолжить кнопкой ▶ в строке. Для ошибок кнопка называется «Повторить».
- Упавшую загрузку файла можно повторить, и она продолжится с того места, где остановилась.
- Заработали настройки, которые раньше ничего не делали:
  - прокси: HTTP или SOCKS5 (`socks5://адрес`), для торрентов только SOCKS5;
  - свой User-Agent;
  - уведомления о завершении и ошибках, когда окно DwV не активно;
  - «Автозапуск загрузок»: если выключить, новые файлы и видео добавляются на паузе.
- Качество видео по умолчанию задаётся в настройках. Оно используется для ссылок из расширения.

## Исправлено

- Торрент из нескольких файлов снова скачивается в собственную папку. Раньше его файлы высыпались прямо в папку загрузок, а «Открыть папку» и удаление с диска указывали на несуществующую папку.
- Magnet-ссылки в истории больше не превращаются в `magnet:`, а ссылки вида `download.php?id=…` докачиваются по правильному адресу. Раньше всё после `?` терялось.
- Имя файла определяется по заголовку `Content-Disposition: filename="…"` (раньше понимался только вариант с `filename*=`). Если сервер не отвечает на HEAD-запрос, DwV пробует GET. Если ссылка перенаправляет на другой адрес, имя берётся из конечного адреса.
- «Очистить завершённые» больше не может удалить чужую запись из истории.
- «Сбросить базу» останавливает загрузки, очищает всю историю и сразу обновляет список.
- Медленная ссылка из браузера (например, .torrent с трекера) больше не задерживает остальные.
- DwV больше не перехватывает magnet-ссылки у другого торрент-клиента при каждом запуске. Если ими уже занимается qBittorrent или другой клиент, DwV просто появляется в «Открыть с помощью».
- Окно открывается быстрее: регистрация в реестре идёт в фоне и только при первом запуске или после переноса программы.
- Настройки не сбрасываются целиком, если в файле не хватает поля. Повреждённый файл сохраняется как `settings.json.bak`.

## Расширение для браузера

- В настройках расширения появились:
  - минимальный размер файла для перехвата: мелкие файлы скачивает браузер;
  - список сайтов, на которых файлы скачивает браузер;
  - качество видео для кнопки «Скачать» и меню страницы.
- Пункт контекстного меню «Скачать через DwV» переведён на язык браузера.

## Совместимость

- База истории обновляется сама. Старые записи остаются на месте, но торренты, добавленные в 0.2.x по magnet-ссылке, восстановить из истории нельзя: ссылка тогда не сохранилась.
- Незавершённые загрузки файлов из 0.2.x продолжаются после обновления, их `.part` подхватывается.
