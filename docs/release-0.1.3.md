# DwV 0.1.3

Менеджер загрузок для Windows. В этом релизе добавлена загрузка видео со страницы для YouTube и других сайтов, кнопка открытия страницы при капче/авторизации и улучшено обнаружение видео.

## Скачать

- `DwV-0.1.3-setup.exe` — установщик (рекомендуется).
- `DwV-0.1.3-portable.exe` — портативная версия.
- `DwV-0.1.3-x64.msi` — MSI.
- `dwv-firefox-1.2.4.xpi` — расширение для Firefox/LibreWolf.

Инструкция по расширению: `extension/INSTALL.md`.

## Что нового

- Попап сразу строит превью по ссылке страницы: обложка, название, площадка и кнопка «Скачать». Для YouTube/Vimeo данные берутся из oEmbed, для остальных сайтов из og:image.
- Контекстное меню браузера: «Скачать видео со страницы». Работает на YouTube и сайтах, где видео не попадает в автоматический список.
- Кнопка «Скачать видео со страницы» в попапе расширения.
- YouTube-видео определяется по `mime`-параметру `googlevideo`, даже если у ссылки нет расширения.
- Ошибка авторизации/капчи: в деталях загрузки появилась кнопка «Открыть страницу». Пройдите проверку в браузере и повторите загрузку из расширения.
- В релиз 0.1.3 входят исправления 0.1.2: cookies, Referer, User-Agent и final_url для файлообменников, защита от HTML-заглушек и дубликатов.

## Ограничения

- Незавершённые торренты и видео не возобновляются после перезапуска приложения.
- DHT и max peers применяются к новой торрент-сессии; лимиты скорости работают сразу.
- XPI не подписан. Для постоянной установки в Firefox Release нужна подпись AMO; используйте LibreWolf/Developer/ESR или временную установку.
- Если сайт требует POST или капчу, приложение не показывает капчу внутри себя: кнопка «Открыть страницу» открывает сайт в браузере, где можно пройти проверку и повторить загрузку.
- Настройки автозапуска, уведомлений, прокси, обрезки имён и авто-распаковки пока не влияют на загрузки.
