# DwV 0.1.8

## Что нового

- В настройках появилась заметная плашка поддержки Ko-fi. Блок «О программе» остался под ней, в самом конце.
- Версия в «О программе» теперь берётся из самого приложения, поэтому больше не отстаёт от сборки.
- Попап расширения стал шире и оформлен в стиле приложения: длинные названия видео и кнопки помещаются, горизонтальная прокрутка убрана.

## Исправлено

- Удаление с файлами работает одинаково для всех загрузок: видео, торрентов, обычных файлов и записей истории. Файл удаляется с диска вместе с остатками `.part`.
- Если файл занят другой программой, DwV повторяет попытку, а при неудаче показывает ошибку с путём, вместо того чтобы молча оставить файл.

## Файлы

- `DwV_0.1.8_x64-setup.exe` — установщик.
- `DwV-0.1.8-portable.exe` — портативная версия.
- `DwV_0.1.8_x64_en-US.msi` — MSI.
- `dwv-firefox-1.2.6.xpi` — подписанное расширение для Firefox/LibreWolf.
