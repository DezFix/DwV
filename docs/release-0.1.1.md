# DwV 0.1.1

Менеджер загрузок для Windows: файлы, видео и торренты в одном приложении. В этом релизе исправлены баги из тестов и добавлены массовое удаление, единая папка загрузок, нормальная кириллица в видео и иконки.

## Скачать

- `DwV-0.1.1-setup.exe` — установщик (рекомендуется).
- `DwV-0.1.1-portable.exe` — портативная версия.
- `DwV-0.1.1-x64.msi` — MSI.
- `dwv-firefox-1.2.1.xpi` — расширение для Firefox/LibreWolf.
- `dwv-firefox-store-kit.zip` — описание и скриншоты для магазина Firefox.

Запустите DwV один раз, чтобы зарегистрировался `dwv://` для автозапуска из расширения. Инструкция по расширению: `extension/INSTALL.md`.

## Что нового

- Все загрузки идут в одну папку из настроек: файлы, видео, архивы, торренты. Убраны отдельная папка торрентов и подпапки категорий.
- Кириллица в именах видео работает: путь берётся из UTF-8-файла yt-dlp с файловым fallback.
- Метаданные видео снова отображаются: разрешение, кодеки, длительность, битрейт, контейнер, FPS.
- Окна консоли yt-dlp, tar, ffprobe и reg скрыты.
- Открытие файла проверяет путь и показывает ошибку вместо белого полноэкранного экрана.
- Массовое выделение: квадратная плитка с типом файла (MP4, ZIP, PDF) работает как чекбокс.
- Новый диалог удаления в стиле приложения: «Убрать из приложения» / «Удалить файлы» и «Запомнить выбор». Настройка в «Дополнительно».
- Улитка перенесена в статус-бар рядом с ограничением скорости.
- Анимации работают даже при системном reduce-motion.
- Ko-fi: ссылка в «О программе» и баннер раз в 14 дней после двух недель использования.
- Исправлены фантомные записи истории после удаления HTTP-загрузки.
- Кнопка «Вставить» в меню добавления и автофокус поля.
- Новые иконки приложения и расширения.

## Проверено

- Добавление файла, видео с кириллическим названием, торрента.
- Детали: файл, видео, пиры.
- Массовое удаление, удаление файлов и истории, «Запомнить выбор».
- Единая папка загрузок.
- Улитка, трей, тема, язык, настройки.
- XPI 1.2.1 загружается в LibreWolf.

## Ограничения

- Незавершённые торренты и видео не возобновляются после перезапуска приложения.
- DHT и максимальное число пиров применяются к новой торрент-сессии; лимиты скорости работают сразу.
- XPI не подписан. Для постоянной установки в Firefox Release нужна подпись AMO; используйте LibreWolf/Developer/ESR или временную установку.
- Настройки автозапуска, уведомлений, прокси, обрезки имён и авто-распаковки пока не влияют на загрузки.
- Одинаковые имена файлов в одной папке могут конфликтовать.
