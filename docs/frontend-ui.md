# UI: стеки конкурентов и что делать с нашим

Дата: 2026-10-21. Это исследование для фронтенда, решение не принято.

## Коротко

- Наш UI на Slint 1.x, стиль `fluent-dark`, два файла на 2141 строку, тёмная тема захардкожена, строки на английском.
- Ближайшие живые конкуренты сошлись на одном стеке: React 19 + TypeScript + Vite + Zustand, оболочка Tauri 2 или Electron. Gopeed отдельно на Flutter.
- «Хромает» обычно не тулкит, а дизайн-система, состояния экранов и плотность. Смена стека сама по себе это не чинит.
- Рекомендация: v1 на Slint, две недели полировки. Миграцию решать после v1 по критериям ниже, не во время фичи.

Отдельно: у XDM на Kotlin/JVM последний релиз в 2020 году, разработка стоит. Varia на Python/GTK4 только Linux. File Centipede на C++/Qt без лицензии. Как образец для миграции они не подходят.

Совпадение стеков у Prism, Firelink и Motrix 2.0 не случайно: веб-разработчиков больше, Vite даёт быстрый цикл, Tailwind и shadcn закрывают компоненты, а Tauri оставляет Rust-бэкенд и не тащит Electron. Motrix 2.0 переехал с Vue 2 на React 19, это показатель направления.

## Что реально влияет на «хромает»

1. Нет светлой темы и переключателя.
2. Мало состояний: пусто, загрузка, ошибка, офлайн, очередь, повтор. Сейчас в основном прогресс и красный текст ошибки.
3. Таблица: плотность, индикатор сортировки, выделение, клавиатура, закреплённая шапка, поведение на тысяче строк.
4. Диалоги: фокус, Esc и Enter, валидация, подтверждение удаления.
5. Типографика и контраст: 10-13px, много приглушённого текста. Проверить WCAG AA и масштаб 125/150% на Windows.
6. Иконки: 11 SVG без единой сетки 16/20/24.
7. Тексты на английском при русскоязычной аудитории.
8. Анимации: панели и прогресс без motion, из-за этого интерфейс кажется резким.

Все восемь пунктов решаются в Slint. Ни один не требует React.

## План на две недели без миграции

1. Токены: spacing 4/8/12/16/24, размеры шрифта 11/12/13/14/16/20, радиусы 6/8/12, высоты контролов 28/32/36. Вынести в `Theme`. 2 дня.
2. Светлая тема и переключатель. 2 дня.
3. Состояния экранов: пусто, ошибка, офлайн, очередь, повтор. 2 дня.
4. Таблица: плотность, сортировка со стрелкой, клавиатура, мультивыбор, шапка. 3 дня.
5. Диалоги: фокус, Esc/Enter, валидация, подтверждение удаления. 2 дня.
6. Иконки и контраст: единый набор, минимум 12px для вторичного текста, проверка DPI. 1 день.

Итого около 10 рабочих дней одним разработчиком. i18n и анимации можно после v1.

## Если всё-таки мигрировать

Вариант A, рекомендуемый: Tauri 2 + React 19 + TypeScript + Vite + Tailwind 4 + shadcn/ui + Zustand. Тот же стек, что у Prism, Firelink и Motrix 2.0. Rust-ядро остаётся, Tauri-команды оборачивают `Queue`, `Database`, настройки. Лицензии MIT и Apache, код можно брать с указанием авторства.

Оценка: 1 неделя на вертикальный срез (список загрузок, добавление, настройки), 4-8 недель на паритет с текущим UI. Дальше отдельно упаковка и регрессия.

Вариант B: Flutter. Не рекомендую. Dart, переписывание, FFI к Rust, ненативный вид, другая экосистема.

Вариант C: Electron. Не рекомендую. Самый быстрый по компонентам, но самый тяжёлый. Motrix 2.0 платит за это.

Риски миграции: WebView2 на Windows, больше памяти и размер, доступность зависит от веба, две кодовые базы, регрессии, сброс дизайна. Переезд во время v1 сдвинет файлы, торренты и расширение.

## Критерии решения после v1

Мигрировать, если набралось два пункта или больше:

1. Фронтендер веб-разработчик, и Slint замедляет его больше чем в два раза.
2. Нужны компоненты, которых нет в Slint: графики, виртуализованные таблицы, сложные анимации.
3. Нативность и размер не важны пользователям.
4. Можно потратить 4-8 недель без новых фич.
5. Проблемы UI входят в топ-3 жалоб.

Остаться, если нативность, один бинарник и простые экраны остаются преимуществом, а боль в дизайне, а не в структуре.

## Что скопировать у конкурентов

Брать паттерны, не код:

1. Prism: окно деталей с графиком скорости и картой соединений, окно добавления, попап статуса подключения.
2. Firelink: свойства загрузки и торрента, настройка колонок, категории, локализация.
3. Motrix: трей, мини-окно, переключатель темы, детали задачи.
4. Gopeed: простой layout, который одинаково работает на десктопе и мобильном.

Не копировать: liquid glass, магазин плагинов, кнопку видео (видео заморожено), тридцать настроек.
