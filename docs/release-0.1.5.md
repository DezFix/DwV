# DwV 0.1.5

Автозапуск Windows, регистрация протоколов в установщике и автообновление yt-dlp.

## Скачать

- `DwV-0.1.5-setup.exe` — установщик (рекомендуется, нужен для автообновления).
- `DwV-0.1.5-portable.exe` — портативная версия.
- `DwV-0.1.5-x64.msi` — MSI.
- `dwv-firefox-1.2.5.xpi` — расширение для Firefox/LibreWolf.
- `latest.json` — манифест обновлений.

## Что нового

- Установщик сразу добавляет DwV в автозапуск Windows и регистрирует `dwv://` и `magnet:`. Расширение может запустить приложение, даже если оно ещё ни разу не открывалось после установки.
- Автозапуск включён по умолчанию и отключается в настройках.
- `yt-dlp` проверяет обновление не чаще раза в сутки и обновляет себя через `yt-dlp -U`. ffmpeg и deno остаются фиксированными.
- Автообновление приложения: при запуске проверяется `latest.json` на GitHub; кнопки «Обновить» и «Пропустить», подписанная установка и перезапуск.
- Сайдбар: раздел «Источники» убран, в «Типах» есть изображения/GIF и торренты.
- Окно запоминает размер и позицию.
- Из шапки убраны кнопки паузы/пуска; улитка в статус-баре выделена рамкой.

## Проверено

- NSIS-установщик прописывает `Run`, `dwv://` и `magnet:`.
- `dwv://` открывает установленное приложение.
- Сборка обновления подписана, `latest.json` читается.
- Тесты cargo/npm и расширения.

## Ограничения

- Незавершённые торренты и видео не возобновляются после перезапуска.
- DHT и max peers применяются к новой торрент-сессии; лимиты скорости работают сразу.
- XPI не подписан AMO. Для постоянной установки в Firefox Release нужна подпись.
- Капча не показывается внутри приложения: кнопка «Открыть страницу» открывает сайт в браузере, после проверки повторите загрузку.
- Приватный ключ подписи обновлений не хранится в репозитории.
