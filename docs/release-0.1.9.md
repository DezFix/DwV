# DwV 0.1.9

## Что нового

- Выбор качества видео в окне добавления: лучшее, 1080p, 720p, 480p. Там же — «Только аудио · MP3» и «Только аудио · M4A».
- Настройка «Соединений на загрузку» (1–32, по умолчанию 8). Если сервер поддерживает Range, файл качается в несколько потоков.
- Разделители между пунктами настроек и подсказки крупнее.

## Исправлено

- В светлой теме подсказки в настройках больше не сливаются с фоном: контраст поднят с 2.75:1 до 5.1:1. В тёмной — с 3.5:1 до 5.4:1.

## Файлы

- `DwV_0.1.9_x64-setup.exe` — установщик.
- `DwV-0.1.9-portable.exe` — портативная версия.
- `DwV_0.1.9_x64_en-US.msi` — MSI.
- `dwv-firefox-1.2.6.xpi` — подписанное расширение для Firefox/LibreWolf.
