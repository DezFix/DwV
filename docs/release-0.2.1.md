# DwV 0.2.1

## Что нового

- Торренты: перед скачиванием открывается окно со списком файлов. Папки выбираются целиком, есть «Выбрать все / Ничего» и размер выбранного.
- В деталях торрента видно каждый файл и его процент загрузки.
- Список загрузок стал таблицей: шапка не уезжает при прокрутке, колонки сортируются по клику, есть размер, статус, прогресс, скорость, «осталось» и дата добавления.
- Под каждой загрузкой второй строкой показан сайт-источник и тип файла.
- «Продолжить», «Пауза» и «Удалить» работают с отмеченными загрузками. Чекбокс в шапке отмечает все сразу.
- DwV появился в Windows в списке «Открыть с помощью» для magnet-ссылок, так что торрент можно открыть прямо из браузера или проводника.

## Исправлено

- Ссылка на `.torrent` без расширения (`download.php?id=…`) больше не сохраняется файлом — открывается как торрент.
- `.torrent` скачивается с cookies, Referer и User-Agent браузера, поэтому приватные трекеры и антилич не отвечают отказом.
- Если трекер отдал торрент под чужим именем или типом, DwV всё равно узнаёт его по содержимому и открывает выбор файлов.
- Если DwV не запущен, браузер сохранит такой файл с расширением `.torrent`, и его можно добавить вручную.
- В окне торрента кнопка «Скачать все файлы» доступна сразу, пока список ещё загружается.
- Плитка торрента подписана `TOR`, а не случайным словом из имени файла.
- Ожидание списка файлов магнита увеличено до двух минут. Ошибка показывается на языке интерфейса, папку можно выбрать всегда.
- Магнит больше не подписывается как «magnet:» — показывается имя из ссылки или «Торрент».
- Однофайловые торренты сохраняются по правильному пути и открываются из истории.
- «Продолжить» для торрента, которого нет после перезапуска, больше не делает вид, что загрузка идёт.

## Расширение для браузера 1.2.15

- Интерфейс расширения говорит на языке браузера: английский для английского, русский для русского. Название и описание в магазине дополнений тоже переводятся.
- Нужен Firefox или LibreWolf 140 и новее: более старые версии не поддерживают обязательное для магазина объявление о сборе данных.
- Файл больше не сохраняется браузером «по пути»: перехват срабатывает до окна «куда сохранить». Это работало не всегда, когда сайт начинал скачивание из встроенного блока (iframe).
- Расширение определяет файл по типу ответа сервера, а не только по расширению в ссылке. Сайты, которые отдают архив как `octet-stream` по адресу вида `/download/12345`, теперь тоже перехватываются.
- После неудачной передачи больше нет цикла «отменил → передал → снова отменил»: если DwV не ответил, файл спокойно скачивается браузером.
- Ссылка на торрент передаётся вместе с cookies браузера, поэтому приватные трекеры её отдают.
- Если DwV выключен или не запущен, расширение не мешает браузеру сохранять файлы как обычно.

## Файлы

- `DwV_0.2.1_x64-setup.exe` — установщик.
- `DwV-0.2.1-portable.exe` — портативная версия, без установки.
- `DwV_0.2.1_x64_en-US.msi` — MSI-пакет.
- `dwv-firefox-1.2.15.xpi` — подписанное расширение для Firefox и LibreWolf.

Как поставить расширение: `about:addons` → шестерёнка → «Установить дополнение из файла…» → выбрать `.xpi`. После установки проверьте, что в попапе расширения включены все три переключателя, а в `about:addons` у DwV есть доступ к сайтам.
