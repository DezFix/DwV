# DwV 0.2.2

## Исправлено

- Файлы с сайтов, которые ограничивают число одновременных соединений, снова скачиваются. Раньше загрузка падала с ошибкой `server returned status 403` (pixeldrain) или `429` (mixdrop), хотя браузер тот же файл сохранял без проблем.
- Теперь при таком ответе DwV не пытается долбить сервер: он перезапускает загрузку одним потоком, как это делает браузер, и файл доходит до конца.
- Если сервер сам сообщает, через сколько секунд повторить (`Retry-After`), DwV это время соблюдает вместо собственной паузы.
- Одиночный запрос в начале загрузки тоже переживает временный `429`, раньше он сразу показывал ошибку.

## Расширение для браузера 1.2.15

Без изменений с прошлой сборки: перехват файлов до окна сохранения, в том числе из iframe, определение по типу ответа, интерфейс на языке браузера. Файлы лежат в релизе 0.2.1 и здесь.

## Файлы

- `DwV_0.2.2_x64-setup.exe` — установщик.
- `DwV-0.2.2-portable.exe` — портативная версия, без установки.
- `DwV_0.2.2_x64_en-US.msi` — MSI-пакет.
- `dwv-firefox-1.2.15.xpi` — подписанное расширение для Firefox и LibreWolf.
- `dwv-chrome-1.2.15.zip` — расширение для Chrome и других Chromium-браузеров.
