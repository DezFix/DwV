# DwV — карточка для Firefox Add-ons (AMO)

## Название

DwV — Download Manager

## Краткое описание (до 250 символов)

Перехватывает файлы и видео с сайтов и отправляет их в DwV: менеджер загрузок для Windows с торрентами, докачкой и ограничением скорости.

## Полное описание

DwV — это менеджер загрузок для Windows и расширение к нему.

Расширение замечает файлы и видео на страницах и передаёт их в приложение DwV. Если приложение закрыто, расширение запускает его по протоколу `dwv://` и повторяет отправку.

Что умеет расширение:
- Перехватывать скачивание файлов: архивы, документы, программы, образы, `.torrent`.
- Находить видео на странице и в сетевых запросах: mp4, webm, mkv, m3u8, mpd.
- Показывать список видео на текущей странице.
- Скачивать выбранное видео в DwV в лучшем качестве.
- Прокручивать страницу к видео и включать воспроизведение.
- Открывать приложение DwV одной кнопкой.
- Скачивать видео со страницы через контекстное меню или кнопку в попапе, если автоматический список пуст.
- Превью по ссылке страницы: обложка, название и кнопка «Скачать» прямо в попапе.
- Отключать перехват целиком или отдельно для файлов и видео.
- Показывать статус подключения к приложению.
- Передавать cookies, Referer и final URL в локальное приложение, чтобы работали загрузки с авторизованных файлообменников.
- Не перезаписывать существующие файлы: DwV сохранит дубликат под новым именем.

Что умеет приложение DwV:
- HTTP/HTTPS-загрузки с докачкой, очередью и лимитом скорости.
- Видео с сайтов через yt-dlp.
- Торренты через librqbit: magnet, `.torrent`, пиры, DHT, лимит отдачи.
- Одна папка загрузок для файлов, видео и торрентов.
- Нижняя панель с метаданными видео и пирами торрента.
- Мультивыбор и удаление с файлами или без.
- Трей, тёмная/светлая тема, русский и английский язык.

Приложение бесплатное, с открытым исходным кодом (GPL-3.0). Скачать: https://github.com/DezFix/DwV/releases/latest

Важно: расширение работает вместе с приложением DwV для Windows. Без приложения оно показывает список видео, но не может передать загрузку.

## Разрешения и зачем они нужны

- `downloads` — отменять загрузку в браузере, если DwV её принял.
- `contextMenus` — пункт «Download with DwV» для ссылок и изображений.
- `webRequest`, `webRequestBlocking` — определять ответы с вложением и медиа-потоки, чтобы передать ссылку в DwV.
- `storage` — хранить переключатели и настройки сайта локально.
- `cookies` — передать cookies текущей загрузки локальному приложению DwV для авторизованных файлообменников.
- `tabs`, `activeTab`, `scripting` — находить видео на активной странице и управлять воспроизведением.
- `http://*/*`, `https://*/*` — перехват возможен на любом сайте, поэтому нужен доступ ко всем http/https страницам.

## Приватность

- Расширение не собирает аналитику и не отправляет данные на внешние серверы.
- Единственный сетевой адрес — локальный `http://127.0.0.1:41763/` на компьютере пользователя.
- Cookies читаются только для URL загрузки и передаются локальному приложению DwV. Они не сохраняются и не отправляются на внешние серверы.
- Настройки хранятся в `storage.local` браузера.
- Ссылки на файлы и видео передаются только локальному приложению DwV.

## Как проверить ревьюеру

1. Установить DwV для Windows: https://github.com/DezFix/DwV/releases/latest
2. Запустить DwV один раз, чтобы зарегистрировался `dwv://`.
3. Установить расширение и открыть страницу с видео, например https://www.w3schools.com/html/html5_video.asp
4. Нажать иконку DwV на панели. В попапе появится видео и статус «DwV запущен».
5. Нажать «Скачать». Загрузка появится в окне DwV.
6. Если приложение закрыто, расширение откроет его и повторит отправку.

## Заметки

- Расширение не работает без приложения. Это компаньон для Windows-приложения, а не самостоятельный загрузчик.
- Для постоянной установки в Firefox Release нужна подпись AMO. В LibreWolf/Developer/ESR можно установить XPI при `xpinstall.signatures.required=false`.
- Исходный код расширения: https://github.com/DezFix/DwV/tree/main/extension
