# DwV 0.1.4

Менеджер загрузок для Windows. В этом релизе: типы файлов в сайдбаре, magnet-ссылки из Windows, запоминание размера окна и автообновление.

## Скачать

- `DwV-0.1.4-setup.exe` — установщик (рекомендуется, нужен для автообновления).
- `DwV-0.1.4-portable.exe` — портативная версия.
- `DwV-0.1.4-x64.msi` — MSI.
- `dwv-firefox-1.2.4.xpi` — расширение для Firefox/LibreWolf.
- `latest.json` — манифест обновлений.

Первый раз 0.1.4 нужно установить вручную. Дальше приложение проверяет обновления на GitHub и предлагает «Обновить / Пропустить».

## Что нового

- Сайдбар: раздел «Источники» убран. В «Типах» теперь видео, аудио, документы/PDF, архивы, программы, изображения/GIF, остальное и торренты.
- Окно запоминает последний размер и позицию.
- Приложение регистрирует обработчик `magnet:`; magnet-ссылки из Windows открываются в DwV.
- Проверка обновлений при запуске: окно в стиле приложения, кнопки «Обновить» и «Пропустить». Установщик обновления подписан, после установки приложение перезапускается.
- Из шапки убраны кнопки паузы/пуска; пауза и продолжение остались в контекстном меню и трее.
- Улитка в статус-баре выделена рамкой.
- Расширение 1.2.4: превью по ссылке страницы, контекстное меню «Скачать видео со страницы», cookies для файлообменников, защита от дубликатов.

## Проверено

- Magnet-регистрация в Windows.
- Новая структура сайдбара и типы.
- Подписанные updater-артефакты создаются.
- Тесты cargo/npm/расширения.
- Расширение 1.2.4 загружается в LibreWolf.

## Ограничения

- Первый раз 0.1.4 установить вручную; автообновление работает со следующего релиза.
- Незавершённые торренты и видео не возобновляются после перезапуска.
- DHT и max peers применяются к новой торрент-сессии; лимиты скорости работают сразу.
- XPI не подписан AMO. Для постоянной установки в Firefox Release нужна подпись.
- Капча не показывается внутри приложения: кнопка «Открыть страницу» открывает сайт в браузере, после проверки повторите загрузку.
- Приватный ключ подписи обновлений не хранится в репозитории; для будущих сборок нужны TAURI_SIGNING_PRIVATE_KEY и TAURI_SIGNING_PRIVATE_KEY_PASSWORD.
