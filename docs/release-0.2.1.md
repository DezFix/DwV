# DwV 0.2.1

## Что нового

- Торренты: перед стартом окно со списком файлов. Папки выбираются целиком, есть «Выбрать все / Ничего» и размер выбранного.
- В деталях торрента — список файлов с процентом загрузки каждого.
- Главный список стал таблицей: липкая шапка, сортировка по клику, колонки «размер», «статус», «прогресс», «скорость», «осталось», «добавлено».
- Вторая строка у файла: сайт-источник и тип.
- «Продолжить», «Пауза» и «Удалить» в списке работают с выделенными загрузками, чекбокс в шапке выделяет всё.
- DwV появился в списке Windows «Открыть с помощью» для magnet-ссылок.

## Исправлено

- Ссылки на `.torrent` без расширения (`download.php?id=…`) больше не скачиваются файлом — они открываются как торренты.
- `.torrent` по ссылке скачивается с cookies, Referer и User-Agent браузера, поэтому приватные трекеры и антилич тоже работают.
- Если трекер отдал торрент под чужим именем или типом, DwV распознаёт его по содержимому и открывает выбор файлов.
- Если DwV не запущен, браузер сохраняет такой файл с расширением `.torrent`, и его можно добавить вручную.
- В окне торрента кнопка «Скачать все файлы» доступна сразу, пока список ещё загружается.
- Плитка торрента подписана `TOR`, а не случайным словом из имени файла.
- Ожидание списка файлов магнита увеличено до двух минут; ошибка показывается на языке интерфейса, папку можно выбрать всегда.
- Магнит больше не подписывается как «magnet:» — показывается имя из ссылки или «Торрент».
- Однофайловые торренты сохраняются по правильному пути и открываются из истории.
- «Продолжить» для торрента, которого нет после перезапуска, больше не врёт, что загрузка идёт.

## Файлы

- `DwV_0.2.1_x64-setup.exe` — установщик.
- `DwV-0.2.1-portable.exe` — портативная версия.
- `DwV_0.2.1_x64_en-US.msi` — MSI.
- `dwv-firefox-1.2.11.xpi` — подписанное расширение для Firefox/LibreWolf.
